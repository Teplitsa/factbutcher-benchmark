# Атрибуция и происхождение данных

## Полный датасет

Русскоязычный фактчекинговый бенчмарк FactButcher из 423 строк доступен по
лицензии
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

## FactButcher Human Benchmark

Проект FactButcher подготовил 274 утверждения для бенчмарка с помощью
LLM-извлечения из реальных запросов в Telegram-продукт FactButcher, последующей
фильтрации, независимого фактчекинга, разрешения разногласий и человеческой
проверки.

Опубликованные утверждения — формулировки для бенчмарка, а не цитаты
пользователей. Публичный датасет не содержит сырых запросов, идентификаторов
пользователей и трасс или других операционных идентификаторов.

## Компонент Provereno.Media

149 утверждений адаптированы из фактчекинговых статей
[Provereno.Media](https://provereno.media/).

Provereno.Media указывает, что его материалы доступны по лицензии
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Правила сайта
доступны по адресу
[provereno.media/site-rules](https://provereno.media/site-rules/).

Каждая строка Provereno.Media содержит:

- `source_name = "Provereno.Media"`;
- исходную статью в `source_url`;
- `source_license = "CC BY 4.0"`;
- ссылку на лицензию в `source_license_url`.

Изменения, сделанные FactButcher, включают отбор статей, извлечение одного
короткого проверяемого утверждения, нормализацию формулировки, перевод
опубликованного вердикта в словарь бенчмарка, проверку утверждения и вердикта,
добавление допустимых альтернативных вердиктов в обоснованных случаях и
упаковку результата в датасет для оценки.

Эта адаптация и атрибуция не означают, что Provereno.Media поддерживает
FactButcher, бенчмарк или последующее использование датасета.
