# Русскоязычный датасет для фактчекинга FactButcher

В этом датасете собраны 423 утверждения на русском языке и результаты их
проверки. Одни утверждения верны, другие — нет, а для некоторых возможны
разные обоснованные ответы.

Здесь можно посмотреть, какие утверждения люди приносят на проверку,
попробовать проверить некоторые из них самостоятельно или использовать весь
набор для сравнения разных инструментов фактчекинга.

## Несколько примеров

| Утверждение | Результат проверки | Откуда взято |
|---|---|---|
| Слоны боятся мышей | Неверно (`FALSE`) | Запрос к FactButcher |
| На западе Китая в чай кладут соль | Верно (`TRUE`) | Запрос к FactButcher |
| Микеланджело говорил, что берет глыбу мрамора и отсекает от нее все лишнее. | Неверно (`FALSE`) | [Provereno.Media](https://provereno.media/blog/2026/05/24/govoril-li-mikelandzhelo-chto-beryot-glybu-mramora-i-otsekaet-ot-neyo-vsyo-lishnee/) |

Это настоящие строки из датасета. В файлах утверждение хранится в поле
`claim`, а результат проверки — в поле `gold_verdict`.

## Как посмотреть все утверждения

Откройте [`CSV-файл`](data/factbutcher_benchmark_v1.csv) прямо в браузере или
скачайте его и откройте в Excel, Google Таблицах или LibreOffice. Каждая строка
таблицы содержит одно утверждение и результат его проверки.

Если хотите сначала найти ответ самостоятельно, скройте столбцы
`gold_verdict` и `acceptable_verdicts`. Для утверждений из Provereno.Media в
столбце `source_url` есть ссылка на опубликованный разбор. Для утверждений,
зависящих от времени, смотрите также `reference_date` — дату, относительно
которой выставлялся вердикт.

## Откуда взялись данные

Датасет состоит из двух частей:

| Часть | Содержание | Строк |
|---|---|---:|
| FactButcher Human Benchmark | Утверждения из реальных запросов в Telegram-продукт FactButcher | 274 |
| Provereno.Media | Утверждения из опубликованных профессиональных фактчеков | 149 |
| **Всего** |  | **423** |

Из запросов к FactButcher с помощью LLM выделялись фактические утверждения.
Затем их редактировали до короткой самодостаточной формы, проверяли и
просматривали вручную. Опубликованные формулировки не являются дословными
цитатами пользователей; исходные сообщения в датасет не входят.

Строки Provereno.Media адаптированы из опубликованных статей. Каждая из них
содержит ссылку на исходный разбор. 149 строк ведут на 146 страниц, потому что
две статьи дают больше одного отдельного утверждения.

Подробнее процесс сбора, проверки и разметки описан в
[`METHODOLOGY.ru.md`](METHODOLOGY.ru.md).

## Если вы хотите проверить модель или сервис

Датасет можно использовать как общий набор вопросов с заранее проверенными
ответами. Для этого:

1. передайте каждое значение `claim` выбранной модели, сервису или своему
   фактчекинговому скрипту;
2. сохраните полученный вердикт вместе с `claim_id`;
3. приведите ответы к меткам `TRUE`, `FALSE`, `MIXED` или
   `INSUFFICIENT_EVIDENCE`;
4. сравните их с эталонными ответами в датасете.

Способ отправки утверждений зависит от выбранного инструмента: для API
понадобится свой небольшой скрипт и настройки доступа. В этом репозитории
находятся сами утверждения и эталонные ответы.

Для сравнимого результата прогоните все 423 строки в одинаковых условиях и
укажите, какую модель, промпт и веб-поиск вы использовали. Отдельно сообщайте,
был ли доступен домен `provereno.media`: система с веб-поиском может найти там
готовый разбор.

В датасете один раздел — `test`. Не используйте эти строки для обучения или
настройки системы, результат которой затем публикуете как независимую оценку.

## Как устроены вердикты

`gold_verdict` — основной результат проверки:

- `TRUE` — утверждение подтверждается;
- `FALSE` — утверждение опровергается;
- `MIXED` — важные части утверждения имеют разный статус либо надёжные
  источники не дают однозначного ответа.

В некоторых случаях допустимы два близких вердикта. Они перечислены в
`acceptable_verdicts`. Поэтому результат можно считать двумя способами:

- **по допустимым ответам:** ответ системы входит в
  `acceptable_verdicts`;
- **строго:** ответ системы совпадает с `gold_verdict`.

`INSUFFICIENT_EVIDENCE` может встречаться среди допустимых ответов, но не
используется как основной вердикт.

| Основной вердикт | Строк |
|---|---:|
| `TRUE` | 189 |
| `FALSE` | 152 |
| `MIXED` | 82 |

В 120 строках допустимо больше одного вердикта.

## Файлы для работы с данными

- [`data/factbutcher_benchmark_v1.csv`](data/factbutcher_benchmark_v1.csv) —
  версия для электронных таблиц. Несколько допустимых вердиктов разделяются
  символом `|`.
- [`data/factbutcher_benchmark_v1.jsonl`](data/factbutcher_benchmark_v1.jsonl)
  — основная типизированная версия для программ. Каждая строка содержит один
  JSON-объект.

Пример загрузки JSONL обычным Python:

```python
import json

with open("data/factbutcher_benchmark_v1.jsonl", encoding="utf-8") as file:
    rows = [json.loads(line) for line in file]
```

С библиотекой Hugging Face `datasets`:

```python
from datasets import load_dataset

dataset = load_dataset(
    "json",
    data_files={"test": "data/factbutcher_benchmark_v1.jsonl"},
)
```

## Поля

| Поле | Что в нём хранится |
|---|---|
| `claim_id` | Уникальный идентификатор утверждения |
| `claim` | Утверждение для проверки |
| `gold_verdict` | Основной эталонный вердикт |
| `acceptable_verdicts` | Все вердикты, допустимые при подсчёте результата |
| `benchmark_component` | Часть датасета: Human Benchmark или Provereno.Media |
| `reference_date` | Дата проверки для зависящего от времени утверждения, если она известна |
| `source_name` | Происхождение строки |
| `source_url` | Ссылка на статью Provereno.Media; пусто для Human Benchmark |
| `source_license` | Лицензия исходного материала, когда применимо |
| `source_license_url` | Ссылка на лицензию исходного материала |

Полное машиночитаемое описание полей находится в
[`metadata/schema.json`](metadata/schema.json).

## Ограничения

- Это относительно небольшой русскоязычный набор.
- Он отражает запросы FactButcher и выбранные материалы Provereno.Media, а не
  все возможные темы фактчекинга.
- Темы и вердикты распределены естественно, а не поровну.
- Некоторые утверждения зависят от времени.
- Даже проверенный человеком вердикт иногда может быть спорным. Несколько
  допустимых меток отражают часть, но не всю неоднозначность.
- Для строк Human Benchmark датасет не содержит полного набора доказательств
  и письменного разбора. Для строк Provereno.Media доступна ссылка на статью.

## Приватность

В датасете нет исходных сообщений Telegram, идентификаторов пользователей и
служебных данных FactButcher. Опубликованы только подготовленные утверждения и
необходимые для работы с ними поля.
