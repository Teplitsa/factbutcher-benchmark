# Русскоязычный фактчекинговый бенчмарк FactButcher

Набор из 423 русскоязычных утверждений для сравнения фактчекинговых моделей,
промптов и систем на одинаковых эталонных метках.

| Компонент бенчмарка | Что он представляет | Строк |
|---|---|---:|
| FactButcher Human Benchmark | Утверждения, полученные из реальных запросов пользователей Telegram, затем независимо проверенные и отрецензированные | 274 |
| Provereno.Media | Утверждения, адаптированные из опубликованных профессиональных фактчеков, со ссылками на исходные статьи | 149 |
| **Полный бенчмарк** |  | **423** |

Все 274 утверждения Human Benchmark образуют один компонент датасета. Запросы
собирались в разные периоды, но история сбора не является частью публичной
структуры данных. Утверждения извлекались с помощью LLM и редактировались в
самодостаточные формулировки для бенчмарка; они не выдаются за цитаты
пользователей.

## С чего начать

Выберите путь под вашу задачу:

| Цель | Что использовать |

## Метки

`gold_verdict` — основная эталонная метка:

- `TRUE`: центральное фактическое утверждение подтверждается;
- `FALSE`: центральное фактическое утверждение опровергается;
- `MIXED`: существенные части имеют разный статус достоверности либо надёжные
  источники расходятся по центральному вопросу.

`acceptable_verdicts` содержит все ответы, которые принимает скоринг. Это не
позволяет считать ошибкой соседнюю обоснованную метку в действительно
неоднозначных случаях. Для строгого сравнения остаётся `gold_verdict`.

`INSUFFICIENT_EVIDENCE` может встречаться только среди допустимых ответов. Эта
метка не используется как основная эталонная.

| Основная метка | Строк |
|---|---:|
| `TRUE` | 189 |
| `FALSE` | 152 |
| `MIXED` | 82 |

В 120 утверждениях допустимо больше одной метки: в 99 утверждениях FactButcher
Human Benchmark и в 21 утверждении компонента Provereno.Media.

## Поля

| Поле | Значение |
|---|---|
| `claim_id` | Стабильный уникальный идентификатор |
| `claim` | Русскоязычное утверждение для проверки |
| `gold_verdict` | Основная эталонная метка |
| `acceptable_verdicts` | Все метки, принимаемые скорингом |
| `benchmark_component` | `factbutcher_human_benchmark` или `provereno_media` |
| `reference_date` | Дата, относительно которой проверялось зависящее от времени утверждение, если она доступна |
| `source_name` | Читаемое название происхождения данных |
| `source_url` | Ссылка на исходную статью Provereno.Media; пусто для Human Benchmark |
| `source_license` | Лицензия адаптированного исходного материала, когда применимо |
| `source_license_url` | Ссылка на лицензию исходного материала |

Машиночитаемая спецификация полей находится в
[`metadata/schema.json`](metadata/schema.json).

## Как оценить систему

Для каждой строки:

1. передайте `claim` проверяемой системе;
2. приведите её ответ к `TRUE`, `FALSE`, `MIXED` или
   `INSUFFICIENT_EVIDENCE`;
3. считайте ответ правильным, если метка входит в
   `acceptable_verdicts`;
4. отдельно сообщите строгую точность по `gold_verdict`;
5. укажите, был ли включён веб-поиск и был ли доступен домен
   `provereno.media`.

Не обучайте систему на тестовых строках, если хотите получить сравнимый
результат. В датасете один сплит — `test`.

## Методология

Human Benchmark основан на утверждениях, с которыми люди действительно
обращались к FactButcher. Компонент Provereno.Media добавляет случаи с
опубликованными профессиональными фактчеками и доступными исходными страницами.

Утверждения и метки прошли независимую проверку, разрешение разногласий и
финальную человеческую проверку. Для части спорных утверждений допустимо больше
одной метки. Полный процесс и ограничения описаны в
[`METHODOLOGY.ru.md`](METHODOLOGY.ru.md).

149 строк Provereno.Media ведут на 146 разных страниц: две статьи дают больше
одного отдельного утверждения.

## Важные ограничения

- Бенчмарк небольшой и содержит русскоязычные утверждения.
- Он отражает запросы FactButcher и выбранные материалы Provereno.Media, а не
  все темы фактчекинга.
- Многие утверждения зависят от времени; используйте `reference_date`, когда
  она указана.
- Система с веб-поиском может найти страницу Provereno.Media с эталонным
  ответом. Указывайте условия доступа, чтобы результаты можно было сравнивать.
- Датасет содержит утверждения, метки и ссылки Provereno.Media, но не полный
  пакет доказательств для каждого утверждения.

## Приватность

Датасет содержит формулировки для бенчмарка, а не сырые запросы из Telegram. В
нём нет идентификаторов пользователей и трасс, сырых записей запросов, закрытых
файлов рецензирования и сырых ответов моделей.
